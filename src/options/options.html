web-digest settings

Leave it empty to use the default. Model names come from the selected provider's own published list.

Disabled: the summary is written in the page's own language. Enabled: the summary is written in Japanese, regardless of the page's language. This applies to every provider, and is saved on its own, without re-entering a credential.

The credential for each provider is kept in this browser profile's extension storage, and is sent only to that provider's own endpoint — Sakura, OpenAI or Claude, whichever one is selected. One run uses one selected provider; nothing is sent to the other two. There is no server belonging to this project. Whoever controls this Chrome profile can read extension storage, and an unpacked extension cannot change that.

OpenAI and Claude each need a browser permission for their own API origin before they can be used. Selecting either one asks for that permission if it has not already been granted.
